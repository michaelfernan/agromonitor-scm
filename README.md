# AgroMonitor – Gestão de Configuração

Repositório único do projeto **AgroMonitor**, aplicativo para uma cooperativa agrícola (cenário acadêmico da disciplina Projeto de Software).

Todos os artefatos do projeto (código, documentação e design) ficam aqui, na sua versão mais recente. Cada colaborador obtém os artefatos com `git clone` ou `git pull`, trabalha na sua cópia local e devolve as mudanças com `git commit` e `git push`.

## Estrutura

| Caminho | Conteúdo | Responsável |
|---|---|---|
| `docs/requisitos.md` | Requisitos do MVP | Analista de requisitos |
| `src/talhoes.py` | Cadastro de propriedades e talhões | Desenvolvedor back-end |
| `src/pragas.py` | Registro de ocorrências de pragas | Desenvolvedor back-end |

## Fluxo de mudanças

1. `git pull` para obter a última versão antes de começar.
2. Alterar ou criar os artefatos localmente.
3. `git status` para conferir o que mudou.
4. `git add .` para preparar as mudanças.
5. `git commit -m "descrição da mudança"` para registrar a versão.
6. `git push` para publicar no repositório remoto.
